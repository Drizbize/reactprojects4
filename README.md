# reactprojects4

> **University project** — BUT Informatique (Computer Science), IUT de Bordeaux · February – March 2026 · individual project
>
> Web app that queries an API (group scores, sounds, puzzles) and offers a home page, a puzzle page, a group leaderboard and a student details page.
>
> **Technologies:** React 19, TypeScript, Vite, React Router

## Getting started

```bash
npm install
npm run dev
```

The API address is set with the `VITE_API_SERVEUR` variable (`.env` file).
